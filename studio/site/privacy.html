Privacy policy

Highlight Studio. Last updated 25 November 2026.

Highlight Studio is a personal desktop app that runs entirely on the user's own Windows PC. This policy explains what data it uses and how.

Data the app accesses

When the user connects a YouTube account, the app requests two Google permissions:

  • Upload videos (youtube.upload): to upload a video the user has chosen, with the title, description, tags and visibility the user has reviewed.
  • View the YouTube account (youtube.readonly): only to read the channel's name and ID, so the app can show which channel is connected.

The app does not read, change or delete any other YouTube or Google data.

How the data is used and stored

  • Videos are uploaded only when the user presses Upload in the app.
  • The Google sign-in token is stored only on the user's own PC, in the app's local data folder. It is never sent to the developer or to any server other than Google's.
  • The app has no servers, no analytics and no advertising. It doesn't collect, sell or share personal data with anyone.

Google API Services User Data Policy

Highlight Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

To disconnect, choose Sign out in the app's Settings, or remove "Highlight Studio" at myaccount.google.com/permissions. Signing out deletes the token from the PC.
