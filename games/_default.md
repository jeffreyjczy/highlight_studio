# Playbook: default (games without their own playbook)

Used when `games\<Game folder name>.md` doesn't exist. The user will add game-specific
playbooks over time. Copy `Arena Breakout Infinite.md` as a template.

## Phases
From the contact sheets, work out where the gameplay is versus menus, loading, lobby
and spectating, and split the session into rounds or matches if the game has them
(look for repeated loading screens, scoreboards, "victory"/"defeat" style screens).

## Moment shorts: 15–60 s (the only type unless a playbook says otherwise)
- Fights, multi-kills and clutches (win or lose), funny moments, close calls, big wins.
- Start 3–5 s before the action. End 2–3 s after it, or on the death.
- Waiting time can be trimmed out with multiple segments.

## Skip
Menus, loading, idle walking, spectating, scoreboards, anything with no visible payoff.

## Layout
Clips are horizontal, full-frame, at the source resolution. Layout hints for the merger's vertical Shorts: none (= `crop`) for gameplay, `blur` for wide UI screens.

## Report
Describe briefly how the game's rounds/matches looked (start and end screens, kill
indicators). The user can turn that into a proper playbook.
